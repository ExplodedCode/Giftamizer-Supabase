# Seed images

Photos used by `dev/seed-test-data.js`, referenced by path from
`dev/seed-data.js`. Everything is a JPEG, 800px or smaller on the long side.

These are for **local development only** - don't use them in the app itself,
in marketing, or on a deployed server.
